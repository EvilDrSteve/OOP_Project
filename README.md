This is part of our OOP (Object Oriented Programming) course in which we have developed a Diner Dash game using C++ and SFML. The game manages a busy restaurant by taking customer orders, serving food and cleaning dishes. The player acts as a waiter who must multitask efficiently between serving, clearing tables, and taking orders. Object-oriented principles such as encapsulation, inheritance, and polymorphism are used. The game will be developed using classes to model the various entities such as the waiter, dishes, chef, customers, tables, and orders.

## Build the project

Use the following command to make the project

```
make
```

## Usage

```
./build/game
```
